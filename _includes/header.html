{%- comment -%} _includes/header.html — the site header and nav, rendered on EVERY page. The links themselves are NOT hardcoded here. They come from _data/navigation.yml, so adding or renaming a nav item means editing that one YAML file. This template only decides how the links are drawn. Two Hyperbolic behaviours worth understanding: 1. THE `alt` CLASS. Hyperbolic has two header styles. Pages with a full- bleed banner use `
`, which renders the header transparent and overlaid on the banner; assets/js/main.js then swaps it to the solid style once you scroll past the banner. Pages WITHOUT a banner use a plain solid header. A page opts into the banner style by setting `banner: true` in its front matter. Note main.js only activates this if an element with id="banner" also exists on the page, so `banner: true` and an actual banner section must go together. 2. THE MOBILE MENU IS AUTOMATIC. There is deliberately no mobile markup here. assets/js/main.js reads this
list and generates the slide-out panel and its toggle button from it at runtime. Anything added to navigation.yml therefore appears in the mobile menu for free. {%- endcomment -%}
